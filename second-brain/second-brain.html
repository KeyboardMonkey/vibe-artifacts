About this atlas

A map, not a monitoring console.

This self-contained HTML visualizes the system you described: a ~770-note Markdown vault, self-hosted Honcho, self-hosted LightRAG, the secondbrain skill, Felicity, and the Hermes / Pi / OpenCode harnesses.

Use it: select a map component, trace a workflow, step through a sample session, simulate the nightly jobs, explore example notes, or work through the sync-decision checklist. Open the file directly in a modern browser; no server or installation is needed.

Scope: no vault files were read and no integrations, configurations, model variants, service health, or automatic injection mechanisms were verified. Product roles and timing are shown as stated in your description, not as universal product defaults.

Examples: chats, note contents, filenames, tags, YAML fields, and the nightly playback order are illustrative. The migration checklist is a set of design questions, not a product feature comparison.

Privacy: no external scripts, fonts, analytics, network calls, or service credentials. The optional remembered color theme is the only value this page writes to browser storage. Session progress and checklist selections stay in page memory and reset on reload.
