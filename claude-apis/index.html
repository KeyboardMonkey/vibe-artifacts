API Endpoint Reference

Analytics API

Base URL: https://api.anthropic.com/v1/organizations/analytics/

Auth: x-api-key with a read:analytics key, plus anthropic-version header

GET /v1/organizations/analytics/users Per-user engagement metrics. Includes chat, Claude Code (commits, PRs, LOC, sessions, tool actions) and Cowork metrics. Params: date or starting_date + ending_date, filter[], group_by[], limit, page
GET /v1/organizations/analytics/summaries High-level org engagement summary per day. DAU, WAU, MAU counts, assigned seats, and adoption rate. Max 366-day range per request. Params: starting_date (required), ending_date, filter[]
GET /v1/organizations/analytics/apps/chat/projects Usage broken down by chat project. Unique users, conversations, messages, creation date, and creator info per project. Params: date (required), limit, page
GET /v1/organizations/analytics/skills Skill usage across chat, Claude Code and Cowork. A sibling /plugins endpoint reports installs and invocations per plugin. Params: date (required), limit, page
GET /v1/organizations/analytics/connectors MCP connector usage across chat, Claude Code and Cowork. Normalized connector names, unique users, conversation and session counts. Params: date (required), limit, page
GET /v1/organizations/analytics/usage, /cost Beta since Oct 2026. Tokens and spend by user, model or product. Replaces the legacy usage_report and cost_report endpoints. Header: anthropic-beta: analytics-usage-cost-2026-08-24

Compliance API

Base URL: https://api.anthropic.com/v1/compliance/ (public docs)

Auth: x-api-key with a Compliance Access Key, plus anthropic-version header

GET /v1/compliance/activities Activity Feed of admin, auth and resource events, newest first. Needs read:compliance_activities. Filters: activity_types[], actor_ids[], created_at range; limit up to 5000
Tracked admin/system events include: Workspace membership additions and removals, API key creation / modification / deletion, account and org setting changes, permission and access control modifications, SSO and authentication events
Tracked resource events include: Chat, file and project creation, views and deletions, skill changes, Compliance API access itself
GET /v1/compliance/apps/chats, /apps/sessions/* Chats, messages, files and session transcripts (Claude Code, Cowork, Chrome, Office). Needs read:compliance_user_data; DELETE needs delete:compliance_user_data.
Full schemas and event types are in the public Compliance API docs. Enable it at the parent org: it covers linked claude.ai and Console orgs and records nothing from before enablement.

The Compliance API can read conversation content

The Analytics API returns aggregated counts only. The Compliance API Activity Feed is metadata only, but a key with the read:compliance_user_data scope reads every chat, uploaded file and session transcript in the org, and delete:compliance_user_data hard-deletes them. Treat that key like a domain admin credential, keep SIEM and eDiscovery keys separate, and agree the scope with your works council before enabling it.

Analytics API

Best for FinOps, IT admins, and team leads who need usage visibility, seat optimization, cost attribution, and adoption reporting. Quick to enable, no NDA required. Endpoints cover summaries, users, projects, skills, plugins, connectors and artifacts, with usage and cost in beta.

Compliance API

Best for security, legal, and compliance teams who need audit trails, eDiscovery and DLP. Self-service for the primary owner; content access and deletion need separate scopes. See the public docs.
